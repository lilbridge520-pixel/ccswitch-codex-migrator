# Security policy

Do not upload real rollout files, SQLite databases, `auth.json`, `config.toml`, scan reports containing chat history, or migration backups to issues or pull requests.

Before migration, make an independent backup. Do not bypass version or schema guards. Unknown schemas are scan-only by design.

For a security issue, avoid public disclosure of credentials or private history. Open a private security report through the repository's supported GitHub channel once the project is published.
